**Date:** 2026-05-14 | **Audience:** 18-21 Indian Gen Z
**What changed from V3:** Videos are clean B-roll only. All text added in CapCut. This is how every real Indian Instagram page does it.

---

## HOW TO USE THIS PACKAGE

1. Download videos from Higgsfield (app.higgsfield.ai → Generations)
2. Open CapCut → New Project → Import video
3. Follow the CapCut Text Guide for each video below
4. For voiceover: paste the ElevenLabs script into elevenlabs.io, select Indian Hindi voice
5. Layer: Video + Voiceover audio + Text overlays = finished reel
